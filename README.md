## 🚀 Featured Projects

### 1. 📊 Bitcoin Price Prediction using Machine Learning
> **Problem:** BTC price is highly volatile — can ML models identify directional signals from historical data?
>
> **Solution:** Built an end-to-end ML pipeline with feature engineering on OHLCV data, trained and compared multiple regression models, and deployed a live **Streamlit web app** for real-time prediction.
>
> **Result:** Working deployed application with a supporting theory paper documenting the methodology.

**Stack:** `Python` `Scikit-learn` `Pandas` `Streamlit` `Jupyter`

[![Repo](https://img.shields.io/badge/View%20Repo-0B1628?style=flat&logo=github&logoColor=white)](https://github.com/dhineshkumar-24/bitcoin-price-prediction)

---

### 2. 🌐 Macro Regime Intelligence — FX Trade Bias System
> **Problem:** How do macroeconomic conditions (GDP, CPI, PMI) translate into directional bias for FX currency pairs?
>
> **Solution:** Built a systematic framework that ingests macro forecast data, classifies economic regimes, and outputs directional FX trade bias signals — connecting fundamental analysis to systematic trading.
>
> **Result:** A fully automated macro-to-signal pipeline applicable to real-world FX trading research.

**Stack:** `Python` `Pandas` `NumPy` `Macro Data APIs` `Regime Classification`

[![Repo](https://img.shields.io/badge/View%20Repo-0B1628?style=flat&logo=github&logoColor=white)](https://github.com/dhineshkumar-24/Macro_Regime_Intelligence-Translating_Economic_Forecasts_into_FX_Trade_Bias)

---

### 3. 📉 HMM Trading Bot — Market Regime Detection
> **Problem:** Markets behave differently in bull, bear, and sideways regimes — static strategies fail to adapt.
>
> **Solution:** Implemented a Hidden Markov Model (HMM) to detect latent market states from price data. Regime labels feed into a rule-based systematic trading strategy that adjusts position bias per regime.
>
> **Result:** A dynamic regime-aware trading system built entirely from statistical principles.

**Stack:** `Python` `hmmlearn` `Pandas` `NumPy` `Scikit-learn`

---

### 4. 🌍 Economic Growth Prediction Model
> **Problem:** Can macroeconomic indicators reliably forecast a country's GDP growth trajectory?
>
> **Solution:** Applied regression and ensemble ML techniques on cross-country economic datasets (World Bank / IMF data). Feature importance analysis revealed which macro variables drive growth predictions.
>
> **Result:** A reproducible ML pipeline for economic forecasting with clear interpretability.

**Stack:** `Python` `Pandas` `Scikit-learn` `Jupyter` `Matplotlib`

[![Repo](https://img.shields.io/badge/View%20Repo-0B1628?style=flat&logo=github&logoColor=white)](https://github.com/dhineshkumar-24/Economic-Growth-Prediction)

---

### 5. 💬 Financial Sentiment Analysis using LSTM
> **Problem:** Can deep learning extract sentiment signals from financial news to predict market direction?
>
> **Solution:** Built an LSTM-based NLP classifier trained on financial text data to detect positive/negative/neutral sentiment from news headlines and economic reports.
>
> **Result:** Demonstrates the combination of NLP and time-series thinking applied to financial data.

**Stack:** `Python` `TensorFlow` `Keras` `LSTM` `NLP` `Pandas`
